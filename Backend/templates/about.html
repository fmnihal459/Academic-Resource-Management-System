About Academic Resource Management System

The Academic Resource Management System (ARMS) is a web-based application developed as part of the Database Management System (DBMS) course. The project demonstrates the practical implementation of relational database concepts through a centralized platform where students can upload, organize, discover, and manage academic resources efficiently.

Project Objectives

The system was designed to simplify academic resource management while encouraging collaboration among students. It also ensures the quality and reliability of shared learning materials through administrator moderation and resource approval.

  • Organized Resource Management
    Store and organize academic resources in a structured relational database.
  • Student Contribution
    Allow registered users to upload, edit, and manage their own learning materials.
  • Efficient Resource Discovery
    Provide searching, filtering, and sorting features for quick access to study resources.
  • Administrator Moderation
    Review, approve, reject, and manage uploaded resources to maintain quality.
  • Structured Categorization
    Classify resources using subjects and resource types for better organization.

Technologies Used

The application was built using a combination of backend, frontend, database, and client-side technologies to deliver a secure, responsive, and user-friendly experience.

Python Flask MySQL HTML5 CSS3 JavaScript
